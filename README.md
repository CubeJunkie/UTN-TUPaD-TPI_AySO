# Trabajo Práctico Integrador: Entorno Virtualizado Linux (Ubuntu 22.04 LTS)
# en Oracle VM VirtualBox y aplicación en Python para cálculo de promedios

Trabajo práctico de la asignatura Arquitectura y Sistemas Operativos
(Tecnicatura Universitaria en Programación, UTN).

## Descripción

Implementación de un entorno virtualizado con Oracle VM VirtualBox, en el que
se instala Ubuntu 22.04 LTS y se ejecuta un programa en Python que calcula
promedios. El proceso completo está documentado en el informe técnico.

## Contenido del repositorio

| Archivo / carpeta | Descripción |
|---|---|
| `informe/` | Informe técnico en formato PDF |
| `promedios.py` | Programa en Python que calcula el promedio de tres notas |
| `capturas/` | Capturas de pantalla de cada etapa del proceso |
| `README.md` | Este archivo |

## Entorno utilizado

- Sistema anfitrión: Windows 11
- Hipervisor: Oracle VM VirtualBox 7.2.22 (con Extension Pack)
- Sistema invitado: Ubuntu 22.04 LTS
- Lenguaje: Python 3.10.12

## Cómo ejecutar el programa

1. Abrir una terminal en Ubuntu y ubicarse en la carpeta del archivo:
   `cd [nombre de la carpeta]`
2. Ejecutar:
   `python3 promedio.py`
3. Ingresar los valores solicitados por consola. El programa muestra el
   promedio calculado.

Ejemplo: al ingresar 7, 8 y 9, el resultado es 8.00
